Privacy policy

N7 Studio · Last updated 27 October 2026

N7 Studio is a personal tool that N7 uses to manage their own YouTube channels. This page explains what it does with data from Google.

Who uses it

Only N7. The tool signs in to YouTube channels that N7 owns. It is not offered to the public and has no other users.

What it accesses

With N7's permission, N7 Studio uses the YouTube Data API to read and update videos on N7's own channels: titles, descriptions, tags, privacy status and similar video details. It does not read anyone else's account.

What it stores

The only thing kept is the sign-in key (a refresh token) for each of N7's channels, stored privately as a secret so the tool can stay signed in. Video details are fetched when needed and are not stored or collected elsewhere.

Sharing

N7 Studio does not sell, share or transfer any data to third parties, and does not use it for advertising. Data is used only to manage N7's own channels.

Google's policies

N7 Studio uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy. N7 Studio's use of information received from Google APIs follows the Google API Services User Data Policy.

Removing access

Access can be removed at any time from the Google account's third-party access page. Doing so stops N7 Studio from reaching the channel straight away.

Contact

Questions can be sent to the developer email shown on the app's Google sign-in screen.
